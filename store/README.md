# ストア用の画像（App Store Connect にアップするもの）

**サイズは 1242 × 2688（6.5インチ枠）。** App Store Connect が受け付けるのは
1242×2688 / 2688×1242 / 1284×2778 / 2778×1284 のいずれかで、
6.9インチ枠の 1320×2868 では**弾かれます**（実際に弾かれた）。

| ファイル | 見出し |
|---|---|
| `00-title.png` | 文字入れなし（タイトル絵そのまま） |
| `01.png` | 勝負を決めるのは、君のオーダーだ。 |
| `02.png` | タスキをつないで、頂点を目指せ |
| `03.png` | 目指すはJPEL制覇 |
| `04.png` | 世界と戦う日本の戦士 |
| `05.png` | 世界記録との戦い |
| `06.png` | オンラインで全国のライバルと争え |

## 作り直し方

```bash
npm pack @fontsource/noto-sans-jp        # フォントはリポジトリに置かない（4.7MB あるため）
tar xzf fontsource-noto-sans-jp-*.tgz
python3 -c "
from fontTools.ttLib import TTFont
for w in ['900','700']:
    f=TTFont('package/files/noto-sans-jp-japanese-%s-normal.woff'%w); f.flavor=None
    f.save('NotoSansJP-%s.ttf'%w)"
python3 make.py                          # src/ のスクショから 01〜06 を作る
```

## 決まりごと（踏んだ穴）

- **見出しは全部2行にそろえる。** 1行の絵が混ざると、そこだけ見出しと画面の間が空いて
  横に並べたときに段差が出る
- **スクショは画面幅ぴったりに置く。** 左右にはみ出させると
  ポイント（46pt→4）・OVR（90→9）・タイム（12:48→12:4）が欠ける
- **切り抜きは「埋まる側の倍率」で。** 高さだけで合わせると、縦長のスクショが横に
  足りなくなって左右に黒い帯が出る
- `src/f.png` は iOS のステータスバー（時刻・電池）が写っているので、
  `f2.png`（上を132px切ったもの）を使う。他の5枚は元から写っていない
