```
【選手が育つようになりました】
・他チーム（CPU・海外）の選手が、途中から伸びなくなっていたのを直しました。これまでは能力が高くなるほど成長が止まり、どのクラブでもOVR80を超えられませんでした。世界にいる強い選手は「最初からそう作られた選手」だけで、その世代が歳を取ると二度と現れない状態でした。

【士気が効くようになりました】
・士気が、実際にはほとんど効いていませんでした。上がる仕組みしか無かったため、数年で全チームの選手が最大値のまま動かなくなっていました。

・ホームの表示を「モラール」から「士気」に変えました。

【移籍】
・出した移籍オファーの返事が来ないことがあったのを直しました。額が足りずに断られたとき・話している間に相手が他所へ移ったときに、通知が出ていませんでした。狙っていた選手が別のクラブに居るので「勝手に移籍した」ように見えていたのもこれです。
・断られた・競り負けた・相手が移った、では来季まで交渉できなくなりません。また出せます。
・オファーを出したはずなのに、チャットにも出ず返事も来ないことがあったのを直しました。出せない相手でもボタンが押せてしまい、押しても何も起きていませんでした。いまは押す前にボタンへ理由が出ます。
・強い選手には格上のクラブから声が掛かるようにしました。
・海外クラブが移籍金を払わずに選手を持って行けたのを直しました。
・クラブの「加入・放出」に出る契約年数が、実際に結んだ契約と違っていたのを直しました。動いた選手がほぼ全員「2年」と出ていました。
・世界の強豪クラブが1年で軒並み格下げされ、数年で消えてしまう不具合を直しました。

【画面】
・シーズン最終戦の結果から順位表のクラブなどを見て戻ると、そこから先へ進めなくなることがあったのを直しました。
・上に並ぶ切り替え（1部/2部/3部・メンバー/カード/掲示板など）が、詳細を開いて戻ると一番左に戻っていたのを直しました。
・フレンド詳細を開くと落ちることがあったのを直しました。
・フレンド申請が来ても数字が出ず、気づけなかったのを直しました。
・下のタブ「オンライン」とホームの「チャット」に、未読の数が出るようになりました。
・チャットに「◯◯にオファー中・返事待ち」が出るようになりました。
・代表チームの「最高」が、代表に選ばれる7人とは関係のない数字だったので消しました。

【走友会・対戦】
```
