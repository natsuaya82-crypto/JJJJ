走友会の掲示板を自由入力にするにあたって、**表示するときだけ**伏せる語の草案です。
**DBには元の文がそのまま残ります**（通報が来たときに何が書かれたのか確認できないと処理できないため）。

決めてほしいのは「この分類ごと入れるか外すか」と「言葉の足し引き」です。

---

## どう伏せるか

該当した部分だけを、その**文字数ぶんの `※`** に置き換えます。

    しねよ                → ※※※よ
    LINE教えて            → ※※※※教えて

行ごと消したり、投稿そのものを弾いたりはしません。**書いた本人の画面でも伏せた形で出します**
（自分だけ素で見えると「通っている」と誤解して繰り返すため）。

### すり抜け対策

素通しの文字列比較だと `し ね` `シネ` `ｼﾈ` `死ね!!` が全部抜けます。比べる前に次を揃えます。

| やること | 例 |
|---|---|
| 全角英数 → 半角、半角カナ → 全角 | `ＬＩＮＥ` `ﾗｲﾝ` → `LINE` `ライン` |
| カタカナ → ひらがな | `シネ` → `しね` |
| 英字は小文字に | `Line` → `line` |
| 記号・空白・繰り返し記号を落とす | `し・ね` `し ね` `しーね` → `しね` |

**元の文は変えません。** 揃えるのは「どこが当たったか」を探すためだけで、
伏せるのは元の文の該当位置です。

### 誤爆について

短い語ほど巻き込みます。実際に起きるもの:

- `しね` … 「おいしねぇ」「まぶしね」
- `ころす` … 「心を殺す」（誤爆ではないが文脈は悪くない）
- `きえろ` … 「消えろ」以外では滅多に出ない

**ひらがな2文字の語は、前後が文字なら当てない**（`おいしねぇ` の `しね` は伏せない）という
逃げ道を1つだけ入れてあります。それでも取りこぼしと巻き込みは残ります。
**完全にはできません。** 取りこぼしは通報とブロックで拾う前提です。

## 分類（この単位で入れる／外すを決めてください）

### A. 攻撃・脅し 〈入れる想定〉

死ね／しね／殺す／ころす／消えろ／きえろ／うざい／うぜぇ／きもい／キモい／
だまれ／黙れ／バカ／ばか／あほ／アホ／クズ／くず／ゴミ／カス／かす／
ぶす／ブス／デブ／でぶ／はげ／ハゲ／무능（外国語の罵倒は入れていません）

※ `バカ` `アホ` は日常語としても出ます。**外すという判断もあり**です。

### B. 差別 〈入れる想定・外さないことを勧めます〉

国籍・出身・障害・性的指向に関する蔑称。
**ここに実際の語を書くと、この文書自体が検索に引っかかるので、実装のファイル側にだけ置きます。**
数は20語ほどを想定しています。

App Store の審査基準1.1（不快なコンテンツ）に直接関わるので、**ここだけは外さないことを勧めます。**

### C. 性的な語 〈入れる想定〉

直接的な語のみ。ほのめかしは拾いません（拾おうとすると誤爆が跳ね上がります）。

### D. 外部への誘導・連絡先 〈判断してください〉

LINE／ライン／カカオ／ディスコード／discord／url／http／https／`＠`で始まるID／
数字が10桁以上並んだもの（電話番号）

**入れると「LINEのスタンプが〜」のような普通の話も伏せます。**
外すと、掲示板から外部へ連れ出す誘導が素通しになります。
未成年の利用を考えると入れる側に倒すのが無難ですが、**うるさく感じるのは確かです。**

### E. 宣伝・勧誘 〈入れない想定〉

「フォローして」「登録して」など。誤爆が多すぎるので、通報で拾うほうが現実的です。

## 置き場所

`src/utils/wordFilter.ts` の1本にします。**掲示板以外（チーム名・監督名・走友会名）も
同じ関数を通す**ことを想定した作りにします。いま自由入力なのはその3つで、
そこは素通しのままなので、同時に通しておくほうが筋が通ります。

一覧を直すのはこのファイルだけ。`npm run check` で「他所に同じ判定を書いていないか」を見張ります。
