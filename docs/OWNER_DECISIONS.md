# オーナーに決めてもらうこと（1枚にまとめる場所）

最終更新: 2026-08-12 / 集約するのは統括。**各セッションは個別にチャットへ投げないこと。**

## 使い方

- 判断が要ることに当たったら、**このファイルではなく調整スレッド（PR #3）に書く。**
  統括がここへ写して、まとめてオーナーへ上げます
- 決まったら `決定` の欄に書いて、担当セッションへ伝える。**行は消さない**
  （同じ議論を2回しないため。`docs/BACKLOG.md` と同じ流儀）
- **「どちらでもいい」ものは載せない。** 載せるのは、答えが違うと作るものが変わるものだけ

## 1. ★13 監督が別チームへ移るとき（実装が待っている）

オーナー決定は出ています ——「**次シーズン開始時に新チームへ就任する。旧チームのシーズン途中の
状態は持ち込まない**」。実装はその形で設計済みですが、決定文に書かれていない穴が3つあります。

| # | 決めてほしいこと | 統括の推し | 決定 |
|---|---|---|---|
| 13-a | オファーを受けたあと、**次シーズンが始まるまでに取り消せるか** | 取り消せる（受けた直後に気が変わることはある。取り消せないと「押したら終わり」になる） | |
| 13-b | 予約している最中に、年1回のランダムオファーが**来るか** | 来ない（もう行き先が決まっているのに別の話が並ぶのは不自然） | |
| 13-c | 旧チームで進行中の用件（退団予定・契約更新の交渉）は、**今季ぶんはそのまま処理してよいか** | そのまま処理する（最後まで指揮するのだから、途中で権限が消えるほうが不自然） | |

## 2. ＋14 退任時に1人だけ連れて行く（実装が待っている）

新機能なので、決定文に無い前提が4つあります。**ここが決まらないと着手できません。**

| # | 決めてほしいこと | 統括の推し | 決定 |
|---|---|---|---|
| 14-a | **移籍金は0円か、払うか** | 払う（`transferFeeFor` の通常額）。0円だと格1のクラブから主力を無償で引き抜けます | |
| 14-b | **本人の同意は要るか** | 要る（`appraiseMove` を通す）。移籍の判断は1本、という決まりを崩さないため | |
| 14-c | 旧チームが**15人を割る**場合は | 連れて行けない（`ROSTER_MIN` は自チームの操作を止める線） | |
| 14-d | レンタル中・引退予定・海外挑戦承認済みは**対象外**でよいか | 対象外（`transferEligibility` の既存の関門をそのまま通す） | |

## 3. 数字（計測を出してから決めるもの）

**まだ聞いていません。** 実装が計測を出した時点でここに数字を貼り、そのうえで決めてもらいます。

| # | 何を決めるか | いま | 状態 |
|---|---|---|---|
| 15 | 代表候補の人数 `NATIONAL_POOL` | 100 | 実装が「日本人総数／OVR分布／代表20人／選外／年代別」を計測中 |
| 1 | レンタル打診の多さ | 23歳以下は貸出歓迎なしでも対象・1人に年3〜4回 | 実装が「誰に何件来るか」を計測中 |
| 6 | 移籍の量（案2＝移籍したくなる確率を抑える） | 1クラブ 5.3人／年 | 統括の回帰修理が入ったので着手可。案を2〜3つ作って比較 |

| # | 中身 | 統括の推し | 決定 |
