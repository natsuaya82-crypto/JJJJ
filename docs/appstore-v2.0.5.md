## 最新情報（What's New）

```
【優勝トロフィーで能力の上限を110まで】
・JPEL1部で優勝すると1つ、ECLで優勝すると1つ、優勝トロフィーが手に入ります。
・トロフィー1つで、自チームの選手の能力ひとつの上限を1だけ上げられます（99から、最大110まで）。カード強化の画面で、99に達した能力をタップしてください。
・上がるのは上限だけです。そこから先はこれまでどおりカード合成で育てます。99から先は上へ行くほど必要な経験値が増えます。

【1000ダウンロード突破記念】
・優勝トロフィーを5つと、「選手を1人つくる」を1回お贈りします。受け取りは8月31日までです。
・「選手を1人つくる」は初年度のみでしたが、この配布ぶんはいつでも使えます。
・8月22日10:00から8月25日9:59まで、カード合成の大成功が2倍になります。

【移籍】
・強い選手が、大きく格の下のクラブへ移ってしまうのを直しました。選手ごとに「どの格のクラブで走れるか」を持たせ、そこから大きく離れたクラブへは移らなくなります。
・世界最高クラスの選手に、どのクラブからも買い取りの打診が来ないことがあったのを直しました。1クラブが1人に出せる移籍金に上限があり、相場に届くクラブがごく一部しか無くなっていました。
・本人が断ると分かっている相手からは、買い取りの打診が来なくなりました。届く件数は変わりませんが、断るだけで終わる話が減ります。
・海外挑戦を認めた選手に、憧れの地域だけでなく海外のクラブ全体から声が掛かるようになりました。憧れの地域のクラブが先に動くのは、これまでどおりです。
・移籍の判断に出場実績が渡っていなかったのを直しました。走っている選手が「1戦も走っていない」と言われることがなくなります。
・加入したときの契約が続いているあいだは、移籍で動かせなくなりました（レンタルは今までどおりできます）。契約は1〜5年で、若い選手ほど長くなります。v2.0.4 までは一律2年でした。
・買い取り打診への本人の返事が、理由だけで結論が出ていなかったのを直しました。「◯◯へは行きたい（出場機会が見込める）」のように、行くかどうかを言うようになります。
・移籍を断る理由に、チーム内の序列が数字で出ていたのを「出場機会が見込めない」に揃えました。会話・通知・入札の画面で同じ言い方になります。
・こちらから打診したとき、相手が乗り気なら乗り気だと返ってくるようになりました。
・移籍金の提示が「額が足りない」で断られたときは、来季まで交渉できなくなります。競り負けたとき・話している間に相手が他所へ移ったときは、これまでどおり交渉禁止にはなりません。

【選手が育つ】
・他クラブの選手も、シーズン中にレースごとに伸びるようになりました。これまでは年に一度だけまとめて伸びていました。1年で伸びる量は変えていません。

【選手をつくる】
・能力の振り分けに下限（60）を設けました。一つの能力を捨てて尖らせると、育てたときに捨てたぶんが戻ってきてしまうためです。

【レース】
・ECL・ランクマッチ・世界選手権で、強い選手どうしのタイムに差が出なくなっていたのを直しました。一定より上は全員おなじ速さで頭打ちになっていました。調子や天候が噛み合った走りが、そのままタイムに出ます。

【移籍市場】
・何も選ばずに検索すると、とても重くなったりアプリが落ちたりしていたのを直しました。5,000人以上をいちどに並べていたためです。100件ずつ表示し、下の「もっと見る」で続きが出ます。

【画面】
・下のタブをiOS 26のガラスにしました。
・チャットの会話から相手クラブを見て戻ると、会話ではなくチャット一覧に戻っていたのを直しました。
・代表選考でも選手の疲労が見えるようにしました。
・プレゼントの中身が「カード0枚」と出ていたのを直しました。
・カード練習の見出しを整理しました。確認のダイアログを読みやすく改行するようにしました。

【そのほか】
・士気の下がりかたが場面によって食い違っていたのを揃えました。
・ドラフトで、昇格したクラブの指名順が最後になっていたのを直しました。

【ランクマッチ】
・9月1日から「第一回ベータ版ランクマッチ」を開催します。開催前から参加でき、参加した人の一覧も見られます。
```
