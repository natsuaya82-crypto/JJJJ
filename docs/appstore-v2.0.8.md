## 最新情報（What's New）

```
【移籍】
・「そのクラブの主力か」の見かたを、クラブ内の序列ひとつにそろえました。これまでは自分の部の選手にしか効いておらず、2部・3部・海外の選手は誰でも引き抜けていました。
・主力を引き抜くときの上乗せを1.4倍にそろえました。これまでは入札だけ1.8倍でした。
・市場価値に今季の出場が入るようになりました。選手の画面に出る額・入札の受諾ライン・出品の希望額が、これまで別々の数字でした。
・獲得オファーを出したときにチャットだけが開き、話が始まらないまま返事も来ないことがあったのを直しました。
・赤字で補強を止められていても、在籍が15人を下回っていればFAは獲れます。これまでボタンからはその道に入れませんでした。

【年俸と移籍金】
・年俸と移籍金に「今季どれだけ走ったか」が正しく入るようになりました。これまで他の部と海外の選手は全員「1戦も走っていない」と数えられていて、年俸も移籍金も本来より安く出ていました。よく走っている選手は高くなります。

【移籍市場】
・海外クラブの選手も移籍リストに並ぶようになりました。海外クラブも買い手として入札します。
・怪我をした選手が移籍市場の一覧から消えていたのを直しました。他の画面からは入札できていました。
・移籍を認めた選手の売出に、海外クラブも手を挙げるようになりました。

【通知・チャット】
・海外クラブからのトレード打診が、ベルに数字は出るのに通知ページに出ず、承諾も拒否もできないままだったのを直しました。
・海外クラブからの買い取り打診で、クラブ名が「他クラブ」と出ていたのを直しました。
・海外クラブからの契約満了の接触に、期限が来ても返事が来なかったのを直しました。

【レンタル】
・レンタル要請を承諾したときに31人になり、レンタル選手は解雇できないため人数を戻せなくなることがあったのを直しました。
・レンタルの残り枠が、画面と実際の受け付けで食い違っていたのを直しました。

【ドラフト】
・CPUの指名が進まなくなり、会場が止まることがあったのを直しました。
・指名されずFAになった選手を他クラブが拾ったとき、契約が結び直されずに翌年また契約満了になっていたのを直しました。

【他クラブ】
・CPUクラブが選手を減らしすぎて16人を下回ることがあったのを直しました。

【選手】
・「育成期／成長期／ピーク／下降期」の札が、その選手の実際の成長曲線から出るようになりました。これまではタイプだけで決めていたので、まだ伸びる選手に「下降期」と出ることがありました。

【オンライン対戦】
・部屋がホスト1人でも開始できてしまうことがあったのを直しました。
・ランクマッチで、同じ選手を2つの区間に置いた提出を受け付けないようにしました。
・レースの結果と暫定順位、ブロックした人の一覧に段位を出すようにしました。

【走友会】
・満員の走友会で参加申請を承認すると、入れないうえに申請が消えてしまうのを直しました。

【表示】
・海外クラブの選手一覧に人数の上限（◯/30）を出すようにしました。
・施設の効き目の数字が、実際に掛かる値と同じところから出るようになりました。
・記録会の距離の呼び名を「ハーフマラソン」にそろえました。
・遊び方の「繰り越せるのはクラブ予算の50%まで」は30%の誤りでした。
・トレーニング計画の「確率35%」は30%の誤りでした。
・天気の呼び名が画面によって「強風」と「風」、「曇り」と「くもり」に分かれていたのをそろえました。
・移籍市場の総年俸に怪我人のぶんが入っておらず、他の画面と食い違っていたのを直しました。

【セーブ】
・保存を交互書き込みにしました。書き込みの途中でアプリが落ちても、完全なセーブが必ず1本残ります。
```
