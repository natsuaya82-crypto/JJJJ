## 最新情報（What's New）

```
【監督】
・監督のオファーが海外クラブからも届くようになりました。受けると海外クラブの監督に就任し、そのリーグで戦います。
・オファーを出すクラブは、その年の成績で変わります。優勝すれば今より上のクラブから、下位に沈むと今より下のクラブから声がかかります。
・退任したときに届く3件のオファーのうち1件は、必ず日本のクラブです。
・監督が去ったクラブの監督名が、2部・3部と海外で「新監督」になっていたのを直しました。

【海外リーグ】
・海外リーグは、どのリーグも日本1部と同じ日に10戦を走ります。これまでは自チームの部と同じ数でした。
・国内の他の部と海外リーグのレースは、日付の順に進みます。
・海外リーグのレースにも区間賞の賞金が出ます。
・海外リーグの選手は、春季10000m・初夏ハーフ・秋季5000mの記録会の日に、同じ距離の海外の記録会（スプリング10000mクラシック／サマーハーフマラソン／オータム5000mクラシック）を走ります。

【移籍・トレード】
・トレードの相手に海外クラブも選べるようになりました。ドラフトの指名権は日本のクラブとだけやり取りできます。
・選手の名前の横の「外」の札をなくしました。

【チーム】
・開幕のときに在籍が20人に満たないクラブには、20人になるまで選手が加入します。これまでは15人まででした。加入する選手の強さはクラブによって違います。

【レース】
・中継を、タスキをつないで途切れずに走る形にしました。先頭のチームは後ろのチームより先の区間を走ります。
・区間の終わりで止まらなくなりました。区間の順位は、一覧の「総合／区間」で切り替えて見られます。

【ランクマッチ】
・次の開催が決まるまで、オンラインのイベントから項目を外しました。決まりましたらお知らせして、また出します。

【他クラブの経営】
・クラブの年間予算を引き上げました。長く続けたときに、他クラブの資金が尽きて補強できなくなるのを防ぐためです。
・選手が育って世界のレベルが上がると年俸も上がりますが、予算は据え置きだったので、6年目あたりから赤字のクラブが出ていました。
```
