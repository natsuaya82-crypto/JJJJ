# 世界陸上（World Athletics）仕様書 v1

旧「世界駅伝(WEC)」を全面的に作り直し、**個人種目＋駅伝の総合世界大会**にする。旧WECの使い捨て仮想生成は破棄する。

---

## 1. 開催サイクル

- **2年サイクル。シーズン終わり（シーズンオフ）に実施。**
- 交互に「予選の年」と「本番の年」を置く：
  - **予選の年**（世界大会が無い年）＝ 地域予選（日本はアジア＋オセアニア予選）。
  - **本番の年**（翌年）＝ 世界陸上本番。前年の予選を勝ち上がった国が出場。
- 例：2027 予選 → 2028 本番 → 2029 予選 → 2030 本番 …

## 2. 本番の規模と地域枠（全20カ国）

| 地域 | 枠 |
|---|---|
| アフリカ | 6 |
| ヨーロッパ | 6 |
| アメリカ大陸（北米＋中南米） | 4 |
| アジア＋オセアニア | 3 |
| 開催国（ホスト）自動枠 | 1 |
| **合計** | **20** |

- 距離走の勢力図に沿ってアフリカ・ヨーロッパを厚めに。
- 開催国は持ち回りで、その年のホスト国は予選免除で自動出場。日本やアジア国が開催国の年は救済ドラマが生まれる。

## 3. 予選（前年・地域別）

- **アジア＋オセアニア予選：約20カ国が争い、上位3カ国が本番へ。**（日本・韓国・中国＋生成のアジア/オセアニア国）。トップ3＝相当ヒリつく。
- 日本が予選落ちした年の本番：日本は出場できない（観戦のみ）。
- 開催国は予選免除。
- 他地域（アフリカ/ヨーロッパ/アメリカ）の予選は日本が出ないので、結果のみ簡易処理で通過国を決める。

## 4. 種目

- **個人種目**：5000m / 10000m / マラソン。
- **駅伝**：3本勝負、各6〜10区（ランダム）、代表20人。ランダムコース。

## 5. 代表選出（OVRではなく持ちタイム）

- 選出基準は **持ちタイム（eventBests）**。OVRでは決めない。
- **日本人は所属を問わない**（国内でも海外クラブ所属でも候補）。`nationality==='JPN'` で集める。
- **個人種目**：各種目、**参加標準記録**（今年＋前年の持ちタイム）を突破した選手が出場。タイム順で発表・メダル。距離別に得意不得意が出る（記録会のタイムが距離別重み付けのため）。
- **駅伝代表20人**：候補（約50人）から **監督（プレイヤー）が選ぶ**。持ちタイム順に並んだ候補から最終20人＋区間配置を采配。
- **個人種目の代表になった選手は、基本、駅伝代表に入らない**（マラソン等の専門家は駅伝を走らない）。
- 監督は **断ることができる**（断ればAIおまかせ配置）。
- **海外国も同じロジック**（各国の選手を国籍で集め、持ちタイムで選出。深追いはしない）。

## 6. 記録会＝代表選考会

- 既存の記録会（年7回）は数を変えない。
- そのうち **5000m・10000m・マラソンの3つを「代表選考会」に位置づけ**。ここで出した持ちタイムが選考・出場資格の基準になる。
- 記録会には自チーム／国内CPU／海外クラブ選手／ドラフト候補が出走し、`eventBests` が貯まる（既存の仕組み）。

## 7. 生成国（実在9カ国以外）

- 実在の選手プールを持つのは9カ国（日本＋外国8：韓国/中国/エチオピア/ケニア/ウガンダ/タンザニア/ヨーロッパ/アメリカ）。
- 予選・本番の“世界感”を出すため、それ以外の国は **強さプロフィール＋距離別の持ちタイムを持たせて生成**（地域傾向：アフリカ強い等）。旧WECの使い捨て仮想とは別物として、ちゃんと国籍・タイムを持たせる。
- 国籍コードの粗さ（オセアニア＝EUR、南米＝USAに丸め）は、必要に応じて国籍コードを追加して対応（後で判断）。

## 8. 得点・総合成績

- 各種目（5000/10000/マラソン／駅伝）で **金5p / 銀3p / 銅2p / 入賞（8位以内）1p**。
- 全種目の合計＝**長距離部門の国別総合成績**。日本の総合順位はこれで決まる。

## 9. パッチ（勲章）

- 代表選出で「**2028 マラソン 日本代表**」形式（年＋種目＋国代表）のパッチ。
- メダル獲得も記録として残す。

## 10. 保留（別途しっかり練る）

- **化け物枠（チーム未所属の怪物／マラソン特化が駅伝を避けて無所属化）は今回は入れない。** 別途設計する。
