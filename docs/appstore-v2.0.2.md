## 最新情報（What's New）

```
【1部・2部・3部の3部制になりました】
・リーグを3部制にしました。全52クラブが、それぞれ自分の部でシーズンを戦います。
・昇格・降格が入ります。各部の上位2チームが昇格、下位2チームが降格します（プレーオフなし）。
・自分の部以外のレースも裏で走るので、順位表も通算成績も自分の部と同じだけ動きます。
・以前から遊んでくださっているデータには、次のシーズンの開始時に32クラブが加わります。

【選手が育つようになりました】
・素質のある選手が能力の上限近くまで伸びます。これまでは上限に届かないまま引退する選手がほとんどでした。
・他チームの選手も同じ基準で育つので、移籍市場に出てくる日本人選手の質が上がります。

【移籍が取り合いになりました】
・良い選手には最大5クラブが同時に手を挙げます。狙っている選手を他クラブに競り上げられるので、増額して勝つか見送るかを選べます。
・移籍金を積んでも、最後に決めるのは選手本人です。「そこで出番があるか」「格上のクラブか」「優勝を争っているか」を見て判断します。自チームの選手を売るときも同じで、本人が納得しなければ成立しません。
・他のクラブは「強いから」ではなく「必要だから」動きます。穴のあるクラブは足りないタイプを狙い、足りているクラブは同じタイプのエースが出ても手を出しません。
・移籍先が決まらなかった選手を、シーズン終わりに問答無用でフリーにしていました。残すか契約を解除するかを選べます。

【クラブの経営】
・予算の決め方を「クラブの規模」1本にまとめました。規模は前年の成績で毎年上下し、1部優勝と3部最下位では予算が4倍違います。
・海外クラブのお金も本物になりました。買えば減り、売れば増えます。これまでは実質いくらでも払える状態で、日本の主力が一方的に引き抜かれていました。

【監督（GM）】
・シーズン終了後、国内の上位チームから就任要請が来ることがあります。解任はありません。在任履歴も残ります。

【オンライン・走友会】
・オンライン対戦の履歴を追加しました。順位・区間タイム・誰が何区を走ったかまで見られます。
・レース中に応援スタンプを送れます。自分の選手の顔でも送れます。
・走友会の掲示板を書き込みの形に作り直し、反応（絵文字）を返せるようにしました。

【世界選手権・日本代表】
・世界選手権のコースを本編と同じものから選ぶようにしました。以前は毎年その場で作っていたため、区間記録が1年で使い捨てになっていました。
・海外リーグも大陸予選も、決め打ちではなく実際にレースを走って順位が決まります。
・日本代表の候補をOVR上位100人にしました。記録会に出ていない選手や海外クラブの選手が候補に出てこなかったのを直しています。

【カード】
・カード選択に並べ替え（入手順／レア度順／種類順）を追加しました。
・完全休養カードは10枚で、同じレア度の好きなカード1枚と交換できます。

【データの保護】
・起動時に、セーブの読み込みが終わるまで待つようにしました。読み込みの前に「はじめから」の画面へ進んでしまう事故を防ぎます。
・読み込みに失敗しても新規作成へは進みません。端末に残っているバックアップから戻せます。

そのほか、契約交渉・通知・順位の数え方・画面表示について多数の修正を入れています。
```
