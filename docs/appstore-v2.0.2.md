## 最新情報（What's New）

```
【選手が育つようになりました】
・素質のある選手が上限近くまで伸びます。これまでは能力を持て余したまま引退する選手がほとんどでした。
・他チームの選手も同じ基準で育つので、移籍市場に出てくる日本人選手の質が上がります。
・自チームの初期選手だけ年齢ぶんの成長が入っておらず、26歳の選手が22歳の能力で始まっていたのを揃えました。

【移籍が「取り合い」になりました】
・良い選手には最大5クラブが同時に手を挙げます。移籍金の逆提示は全クラブへ一斉に出せ、払えないクラブはその場で辞退します。最後にどこへ行くかは本人の希望で決まります。
・狙っている選手を他クラブに競り上げられるようになりました。増額して勝つか、見送るかを選べます。
・自チームの選手を売るときも、本人が納得しなければ成立しません。「そこで出番があるか」「格上のクラブか」「優勝を争っているか」「憧れの地域か」を見て判断します。
・他のクラブは「強いから」ではなく「必要だから」動きます。山に穴のあるクラブは山型を狙い、足りているクラブは同じタイプのエースが出ても手を出しません。

【クラブの経営】
・予算の決め方を「クラブの規模」1本にまとめました。規模は前年の成績で毎年上下し、1部優勝と3部最下位で予算は4倍違います。
・海外クラブのお金も本物になりました。買えば減り、売れば増えます。これまでは実質いくらでも払える状態で、日本の主力が一方的に引き抜かれていました。

【リーグ】
・2部・3部がシーズンを通して0ptのまま動いていませんでした。自分の部以外も裏で走ります。
・昇格・降格を入れました（各部の上位2チームが昇格、下位2チームが降格）。
・順位表を部ごとに分けました。2部の首位が9位、3部の首位が13位と出ていたのが直ります。

【監督（GM）】
・シーズン終了後、国内の上位チームから就任要請が来ることがあります。解任はありません。
・監督の在任履歴を残すようにしました。

【オンライン】
・対戦履歴を追加しました。順位・区間タイム・誰が何区を走ったかまで見られます（60日で消えます）。
・レース中に応援スタンプを送れます。自分の選手の顔で送ることもできます。
・対戦中・順位表・履歴のすべてにGM名を出すようにしました。

【走友会】
・掲示板を書き込みの形に作り直し、反応（絵文字）を返せるようにしました。
・メンバー一覧から直接フレンド申請できます。長押しでその人のロスターも見られます。

【世界選手権・日本代表】
・世界選手権のコースを本編と同じものから選ぶようにしました。これまでは毎年その場でコースを作っていたため同じコースが二度と来ず、区間記録が1年で使い捨てになっていました。同じ大会が何度も開かれるので記録が貯まります（国内の記録とは別の表に貯まります）。
・海外リーグと大陸予選も、決め打ちではなく実際にレースを走って順位が決まります。
・日本代表の候補をOVR上位100人にしました。記録会に出ていない選手や海外クラブの選手が候補に出てこなかったのを直しています。

【データの保護】
・起動時にセーブの読み込みが終わるまで待つようにしました。読み込みの前に「はじめから」の画面へ進んでしまう事故を防ぎます。
・読み込みに失敗しても新規作成へは進みません。端末に残っているバックアップから復旧できます。

そのほか、移籍・契約交渉・通知・順位の数え方・画面表示について多数の修正を入れています。
```
